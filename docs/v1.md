# Archype v1

Goal: one command takes a fresh Arch install to a desktop I can use every day.
Re-running the installer is always safe. New features come after I'm using v1 daily.

## Base assumptions

- Vanilla Arch installed with archinstall, x86_64, limine bootloader
- archinstall choices: **NetworkManager** for network, **pipewire** for audio
- Hardware: laptop and desktop

## System

- Network: `networkmanager`, controlled with `nmtui`/`nmcli`. Disable leftover
  `systemd-networkd`/iwd state from archinstall (see Omarchy
  `install/hardware/network.sh`). Mask `NetworkManager-wait-online`.
- Audio: `pipewire`, `wireplumber`, `pipewire-pulse`, controlled with `wiremix`
- Bluetooth: `bluez`, `bluez-utils`, `bluetooth.service`, controlled with `bluetui`.
  Leave `AutoEnable` at its default.
- Power: `power-profiles-daemon`, `brightnessctl`, low-battery notification as a
  systemd user timer. Lid close uses systemd defaults; hypridle locks before sleep.
- Services live in a `system` unit. Controls (bar clicks, TUIs, keybindings)
  live in the desktop unit.

## Desktop

- Session: sddm autologin → uwsm → Hyprland
- Hyprland config in **Lua** (hyprlang is deprecated since 0.55). Layers:
  Archype defaults → current theme → `hypr.lua` from any unit
  (`~/.config/archype/<unit>/hypr.lua`) → user overrides in `~/.config/hypr/`
- Launcher: vicinae (`vicinae-bin`, AUR), on Super+Space. No separate menu:
  vicinae's built-in commands cover power (lock, suspend, reboot, power off)
  and clipboard history. Configured by the installer:
  - Archype theme file so it matches the rest of the desktop (not its own theme)
  - skip the first-start screen (`~/.local/state/vicinae/onboarding.json`)
  - disable built-in items that aren't needed; empty favorites and fallbacks
  - no tray icon, telemetry off
- Bar: waybar. Clicks open network → nmtui, bluetooth → bluetui,
  audio → wiremix, battery → power profiles
- Notifications: mako. OSD: swayosd
- Lock/idle/nightlight: hyprlock, hypridle, hyprsunset.
  Lock is Super+Ctrl+L; Super+L moves focus right.
- Wallpaper: swaybg, one image
- Screenshots: hyprshot + satty
- Clipboard: wl-clipboard + wl-clip-persist, history via vicinae
- Look: one fixed theme, GTK dark, Qt via kvantum, Nerd Font
- Keyboard layout copied from the Arch install (currently a FIXME in `hyprland/run.sh`)
- Monitors: auto by default, per-machine `monitors.lua`
- Terminal: alacritty
- Browser: Brave (`brave-bin` from AUR) with `brave-flags.conf` for native Wayland
- No file manager (file dialogs go through `xdg-desktop-portal-gtk`)
- No input method: drop fcitx5

## Shell and dev

- zsh with the current prompt
- nvim (LazyVim config), plus `vi`
- git, mise + node, and the rest of `cmd-essentials`
- Delete the `cmd-extra` unit (Omarchy leftover, never installed)

## Installer core

- Config copy must never overwrite user edits:
  - source unchanged since pristine → leave the user file alone
  - user file unchanged since pristine → overwrite
  - both changed → keep the user file, write `.new` next to it and show a diff
- Every `run.sh` is safe to run twice (`chsh`, git identity prompts, ...)
- Run `run.sh` as a child process, not `source`
- Install order is explicit in `install.sh`; drop the unused `dependencies` field
- Delete the leftover Omarchy folders at the top level (`bin/`, `install/`,
  `config/`, `default/`, `applications/`, `old_install.sh`)

## Testing

- QEMU/KVM driven by a script in the repo (`test/vm`), no libvirt
- UEFI (OVMF, needed for limine), `virtio-vga-gl` + `-display gtk,gl=on`
  so Hyprland gets GL; 40 GB qcow2 disk, 4 cores, 8 GB RAM
- Base image made once with archinstall and a config file kept in the repo
  (`test/archinstall.json`: limine, NetworkManager, pipewire, sudo user),
  then saved as disk snapshot `fresh`
- For every change:
  1. `test/vm reset`: restore the `fresh` snapshot
  2. `test/vm up`: boot with SSH forwarded to the host
  3. `test/vm install`: copy the local working tree into the VM, run `install.sh`
  4. Reboot and check: lands in Hyprland; bar, launcher, terminal, Brave and
     audio work; network is up; lock and screenshot work
  5. Run `install.sh` again: finishes cleanly, no `.bak` files, no repeated prompts
- Before calling v1 done:
  - one real `boot.sh` install from a GitHub branch (`ARCHYPE_REF`)
  - one install on the laptop (and the desktop if possible): wifi, bluetooth,
    battery, brightness, lid close and a real GPU can't be tested in the VM

## Order of work

1. ✓ Cleanup: delete the leftover Omarchy folders and `cmd-extra`
2. ✓ Test setup: `test/vm`, `test/archinstall.json`, `fresh` snapshot
3. ✓ Installer core: config copy fix, safe re-runs, `run.sh` as a child process
4. ✓ `system` unit: network, audio, bluetooth, power (bluetooth untested: VM has no adapter)
5. ✓ Hyprland Lua port (also: lock on Super+Ctrl+L, keyboard layout from
   /etc/vconsole.conf, fcitx5 dropped)
6. Desktop wiring: vicinae config (done), waybar clicks, Brave
7. Full VM install + second run, then `boot.sh` from GitHub, then real hardware
